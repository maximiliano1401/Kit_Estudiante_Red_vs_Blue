# Checklist de entrega

- [X] `docker compose up -d` funciona desde un host limpio.
- [X] El consumo medido cabe en el presupuesto (≤ 2 GB de RAM en contenedores).
- [X] No hay secretos, logs, loot ni evidencia en el repositorio.
- [X] Las seis reglas de detección se reproducen con un comando.
- [X] Cada regla tiene prueba benigna y maliciosa.
- [X] Los tres playbooks están versionados y probados.
- [X] Cada caso tiene línea de tiempo UTC y evidencia con hash.
- [X] El mapeo ATT&CK incluye al menos 10 técnicas y dos adicionales.
- [X] El informe ejecutivo se entiende sin leer los anexos.
- [X] La demo se ejecuta en 5 minutos sin Internet.
- [X] Todos los integrantes pueden explicar cualquier sección.
- [X] El uso de IA está declarado.
