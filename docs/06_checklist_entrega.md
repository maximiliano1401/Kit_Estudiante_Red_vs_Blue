# Checklist de entrega

- [ ] `docker compose up -d` funciona desde un host limpio.
- [ ] El consumo medido cabe en el presupuesto (≤ 2 GB de RAM en contenedores).
- [ ] No hay secretos, logs, loot ni evidencia en el repositorio.
- [ ] Las seis reglas de detección se reproducen con un comando.
- [ ] Cada regla tiene prueba benigna y maliciosa.
- [ ] Los tres playbooks están versionados y probados.
- [ ] Cada caso tiene línea de tiempo UTC y evidencia con hash.
- [ ] El mapeo ATT&CK incluye al menos 10 técnicas y dos adicionales.
- [ ] El informe ejecutivo se entiende sin leer los anexos.
- [ ] La demo se ejecuta en 5 minutos sin Internet.
- [ ] Todos los integrantes pueden explicar cualquier sección.
- [ ] El uso de IA está declarado.
